# Todo Proje Kod Standartları

## Genel Kurallar
- Sadece gerekli olan dosyaları oluştur
- Mevcut dosyaları düzenlemeyi yeni dosya oluşturmaya tercih et  
- Açık ve anlaşılır değişken/fonksiyon isimleri kullan
- Kod tekrarından kaçın (DRY prensibi)

## Dosya ve Klasör Yapısı
```
Todo/
├── src/
│   ├── components/
│   ├── utils/
│   └── styles/
├── public/
├── tests/
└── docs/
```

## Kod Formatları

### JavaScript/TypeScript
- camelCase değişken isimleri
- PascalCase component isimleri
- 2 boşluk indentasyon
- Tek tırnak kullan
- Noktalı virgül kullan

### CSS/SCSS
- kebab-case class isimleri
- 2 boşluk indentasyon
- Alphabetical property sıralama

### HTML
- 2 boşluk indentasyon
- Küçük harf tag isimleri
- Semantic HTML kullan

## Commit Mesajları
```
type(scope): açıklama

feat: yeni özellik
fix: hata düzeltmesi  
docs: dokümantasyon
style: format değişikliği
refactor: kod yeniden düzenleme
test: test ekleme/düzeltme
```

## Test Standartları
- Her component için test yaz
- Minimum %80 code coverage
- Jest ve Testing Library kullan

## Performans
- Lazy loading uygula
- Image optimization kullan
- Bundle boyutunu minimize et
- Memoization uygula

## Güvenlik
- Input validation yap
- XSS koruması uygula
- HTTPS kullan
- Environment variables'ı .env'de sakla
